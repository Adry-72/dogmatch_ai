Il Progetto

Cosa e' DogMatch e quale problema risolve

DogMatch funziona come un'app di dating, ma per cani: gli utenti creano un profilo per il proprio cane, scorrono i profili di altri cani nella zona, inviano like e — quando l'interesse e' reciproco — si crea un match che apre una chat tra i proprietari. Disponibile su Web, iOS e Android.

⚠ Il Problema

  • Trovare compagni di gioco o partner per l'accoppiamento e' difficile.
  • Ci si affida al caso nei parchi o a gruppi Facebook disorganizzati.
  • Nessun filtro per razza, eta', carattere o distanza.
  • Nessuno strumento dedicato e sicuro per incontri tra cani.
→

✓ La Soluzione DogMatch

  • Profili cane dettagliati con foto, razza, taglia, pedigree.
  • Feed discovery geolocalizzato con filtri per intento e distanza.
  • Sistema like/match reciproco con chat real-time.
  • Chatbot AI SnoutBot per assistenza personalizzata 24/7.
  • Notifiche push multicanale su tutte le piattaforme.

Funzionalita' Principali

Tutto quello che puo' fare un utente su DogMatch

PROFILO CANE
Registrazione 2 step: dati utente + dati cane. Upload foto, 26 razze, pedigree PDF, geolocalizzazione, bio e info sanitarie.
DISCOVERY
Feed card scorrevoli con swipe. Filtri: intento (gioco/accoppiamento), distanza (provincia/regione). 50 cani per batch. Ordine casuale.
MATCHING
Like reciproco = match automatico. Notifica push istantanea a entrambi i proprietari. Regole razza + sesso per accoppiamento.
CHAT REAL-TIME
Messaggi P2P tra match confermati. Socket.IO: typing indicator, consegna istantanea. Soft-delete e segnalazione utenti.
SNOUTBOT AI
GPT-4o con 14 tool: cerca cani, prenota parchi, risponde a domande, memorizza preferenze, ricerca web live con Tavily.
NOTIFICHE PUSH
3 canali: DB + Socket.IO + Expo Push. Tipi: richiesta match, match accettato, messaggio. AI proattiva ogni 5 minuti.
ADMIN PANEL
Dashboard KPI: utenti, match, segnalazioni. Verifica pedigree, blocco account, cambio ruolo. Su web e mobile.
MAPPE
Mappa Leaflet interattiva sul web. GPS via expo-location su mobile. Filtri geografici nel discovery feed.

SnoutBot — L'Assistente AI

GPT-4o con tool-calling orchestrato, RAG pre-fetch e memoria persistente

1 — Intent Detection

Cosine similarity embedding vs centroide di 10 frasi prototipo. Se score ≥ 0.35: e' una ricerca cani → pre-fetch RAG. Fallback: 29 keyword stem italiani se il modello non e' disponibile.

2 — RAG Pre-fetch

Arricchisce la query con il profilo del cane dell'utente. sentence-transformers (384-dim) trova top-5 cani. Li inserisce nel system prompt: GPT-4o risponde senza tool-call aggiuntivo.

3 — System Prompt Contestualizzato

context (da Node.js) + identita' SnoutBot + nome utente + memoria AI persistente + notifiche non lette + RAG. Ogni risposta e' personalizzata sull'utente reale.

4 — Tool-Calling Loop (max 5 iter)

finish_reason='stop' → risposta finale. finish_reason='tool_calls' → esegui tool, aggiungi risultato, itera. Tutti i tool sono asincroni (asyncio.to_thread per CPU-bound).

Il Sistema di Matching

Like, dislike, match reciproco e discovery feed

🌳 Intento: GIOCO

  • Aperto a tutti i cani — nessuna restrizione di razza.
  • Nessun vincolo di eta' o sesso.
  • Notifica: "Il tuo cane ti invita a giocare!"
  • Match se like reciproco sullo stesso intento.

♥ Intento: ACCOPPIAMENTO

  • Stessa razza + sesso opposto obbligatori.
  • Cane deve avere almeno 1 anno di eta'.
  • disponibilitaRiproduttiva deve essere attiva.
  • HTTP 422 con messaggio esplicativo se regola violata.

Punti di forza e Conclusioni

Cosa rende DogMatch un progetto solido e ben strutturato

Architettura pulita
4 repo con responsabilita' nette. Nessun client chiama mai il servizio AI direttamente. backend_node e' l'unico gateway autenticato.
AI contestualizzata
SnoutBot conosce profilo, cane, match e preferenze dell'utente. Non e' un chatbot generico ma un assistente personalizzato.
Real-time completo
Socket.IO su tutte le piattaforme. Push Expo per raggiungere l'utente anche con l'app chiusa o in background.
Cross-platform
Un'unica API REST serve web e mobile. storage.js astrae SecureStore e localStorage con la stessa interfaccia.
Sicurezza multi-layer
JWT, bcrypt, rate limiting, validazione input express-validator e verifica partecipazione nelle chat P2P.
Scalabilita' del dato
Embedding con cache LRU + persistenza MySQL. Background scanner ogni 5 min senza bloccare l'event loop.
